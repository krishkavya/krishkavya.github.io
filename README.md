# Kavya Krishnan — Personal Portfolio Website

A sleek, high-performance personal portfolio website engineered for **Kavya Krishnan** (Software Engineer at Schneider Electric & FOSS@Amrita alumnus). Built with modern HTML5, Tailwind CSS, and vanilla JavaScript with zero build dependencies, ready to deploy instantly to GitHub Pages.

---

## 🌟 Key Features

* **Theme System**: Seamless Dark / Light mode toggle with state saved in `localStorage`.
* **Dynamic Typing Animation**: Smooth animated headline rotating through core expertise areas.
* **Experience Timeline**: Detailed career progression across Schneider Electric (Software Engineer I, Graduate Engineering Trainee, Intern) and FOSS@Amrita.
* **Featured Projects**: Filterable project showcase featuring HEMS Telemetry Platform, `indic-ocr`, Concurrent Network Printing System, `wscontest`, and algorithmic tooling.
* **Skills Matrix**: Categorized technical competencies, verified assessments (Python), and LinkedIn endorsements (Problem Solving, Communication, Leadership).
* **Interactive Contact**: One-click copy email (`krishkavya03@gmail.com`) with floating toast notification and direct contact form.
* **Mobile First & Responsive**: Optimized across desktop (1920x1080), tablet (768px), and mobile (375px).

## 🚀 How to Deploy to GitHub Pages (`krishkavya.github.io`)

Because this project uses pure HTML5, Tailwind CSS, and vanilla JavaScript without heavy bundlers, you can deploy it directly:

### Option 1: Using Git
```bash
git init
git add .
git commit -m "feat: launch modern portfolio website"
git branch -M main
git remote add origin https://github.com/krishkavya/krishkavya.github.io.git
git push -u origin main --force
```

Your website will automatically be live at **[https://krishkavya.github.io/](https://krishkavya.github.io/)**!

### Option 2: Local Testing
You can preview the website locally using Python's built-in server:
```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080` in your web browser.
